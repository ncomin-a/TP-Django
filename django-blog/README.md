# django-blog

Mi proyecto consiste en agregar un blog personal a mi portfolio usando Django. En el blog puedo crear y publicar entradas como administrador, y los usuarios pueden dejar comentarios en ellas. Además, como administrador, ademas puedo eliminar los comentarios que quiera desde el panel de administración de Django.

Las imágenes subidas al blog se ajustan con Pillow, sin cambiar su proporción ni recortar su contenido. Para instalar las dependencias del proyecto:

```bash
pip install -r requirements.txt
```
